## Project Overview

This project analyzes Major League Baseball data from the Lahman Baseball Database, a relational dataset containing 27 interconnected tables. The database includes historical records covering players, teams, batting, fielding, salaries, awards, managers, colleges, parks, and attendance.

## Project Objective

The objective was to query a complex relational database and produce meaningful insights into baseball history and performance. The analysis explored player achievements, team records, salary and attendance patterns, positional performance, and long-term statistical trends.

## Technologies Used
- PostgreSQL
## Techniques and Methodology Used

- Common table expressions (CTEs)
- Correlated subqueries
- `LATERAL` joins
- PostgreSQL `DISTINCT ON`
- Conditional aggregation and segmentation
- Group-wise maximum analysis
- Multi-table relational joins
- Self-joins for longitudinal comparisons
- Time-series and year-over-year analysis
- Multi-stage analytical query design
