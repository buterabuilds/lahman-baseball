## Project Overview
This project analyzes Major League Baseball history using the Lahman Baseball Database. It combines player, team, salary, fielding, attendance, award, and All-Star records to answer both structured and open-ended baseball questions.

The analysis progresses from foundational SQL querying to advanced database techniques, including correlated subqueries, lateral joins, calculated date fields, and recursive common table expressions. Topics include player career records, offensive trends, payroll and team performance, attendance patterns, award recipients, and connections between generations of All-Star players.

## Project Objective
The objective of this project was to develop practical SQL proficiency by transforming a large relational sports database into meaningful historical and performance insights.
Key goals included:
- Retrieving and combining information from multiple related tables
- Calculating player, team, and league-level performance metrics
- Identifying historical trends in strikeouts, home runs, salaries, wins, and attendance
- Evaluating relationships such as payroll versus wins and team success versus attendance
- Comparing player groups using defined performance criteria
- Applying advanced PostgreSQL features to solve grouped, sequential, and network-style problems
- Communicating findings through clear, reproducible queries

## Technologies Used
- PostgreSQL

## Techniques and Methodology Used

- Common table expressions (CTEs)
- Correlated subqueries
- `LATERAL` joins
- PostgreSQL `DISTINCT ON`
- Conditional aggregation and segmentation
- Group-wise maximum analysis
- Multi-table relational joins
- Self-joins for longitudinal comparisons
- Time-series and year-over-year analysis
- Multi-stage analytical query design
